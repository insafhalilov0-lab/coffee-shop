# coffee-shop

Сайт кофейни «Кофе & Точка».

## Что использовал
- HTML: семантическая верстка, формы
- CSS: Flexbox, тени, эффекты при наведении (`:hover`)
- CSS: типографика (шрифты, размеры, выравнивание)

## Особенности проекта
- Главный экран с разделением на две колонки
- Блок с преимуществами (карточки в ряд)
- Меню с ценами
- Форма для бронирования столика
